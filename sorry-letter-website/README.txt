# Sorry Letter Website ♡

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `Duvet - Boa - (best part loop).mp3` into the repository's main/root folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish and open the URL shown there.

The website attempts to autoplay the song when the page opens. Important: browsers often block sound that starts without a user gesture, so if autoplay is blocked, the page shows a one-tap button to start the music.
